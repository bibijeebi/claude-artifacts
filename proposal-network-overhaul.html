iMac, Home Server & 5-Gig Network

Bottom Line Up Front

You're paying for 5 Gbps up and 5 Gbps down fiber and strangling it through a router that probably caps at 1 gig. This proposal fixes the whole stack in three phases that can be funded one at a time: (1) an M4 iMac as the daily driver so you're off the Windows box you hate, (2) that same PC wiped and reborn as a headless Linux server sitting in the corner doing real work, and (3) a UniFi multi-gig network (gateway, switch, wired drops, indoor + backyard WiFi) that delivers the speed you're already paying for. Lean start is just the iMac (~$1,170 base, ~$1,349 recommended); full buildout lands near $4,000, spread across months.

The Goal

Right now the fast fiber hits a slow router and most of it evaporates. You want Apple on the desk because you actually like working on it, you want the Windows machine to stop being a Windows machine, and you want the network to reach the whole house and the backyard on wire and good WiFi. This proposal is the clean version of all three at once, built so each piece stands on its own and pays for itself in use.

First thing to confirm

How does the fiber hand off into the house? Most 5 Gig plans drop an ONT (the fiber-to-Ethernet box) with an RJ45 port, but some hand you a fiber strand you plug straight into an SFP module. This matters because it decides which WAN port on the gateway you use. The gateway below covers both, so either way you're fine, just worth knowing before you order.

Phase 1 — The iMac

The current 24-inch iMac runs the M4 chip. List is $1,299 base (16GB, 256GB, 8-core, two ports) and $1,499 for the 10-core / four-port. But you're a WGU student, so Apple Education pricing applies and knocks ~$130–150 off: the base shows $1,169 and the 10-core / 4-port lands at $1,349. Get the 4-port, the extra ports and GPU cores age better and a desktop refresh is expected later in 2026, so you don't want to stretch for top trim on a chip near end of cycle. It's in stock for pickup at Apple Crabtree Valley Mall (free delivery showed Fri Jun 5), but this is a next-month buy per BIAR anyway.

Onboard Ethernet on the iMac is gigabit, with a 10 GbE upgrade offered as a build-to-order option. Realistically you don't need it, a single machine almost never pulls more than a gig or two, and if you ever want multi-gig to the desk a Thunderbolt 10 GbE adapter works on both the iMac and the M1 Air. This becomes your SketchUp machine and your daily driver.

Phase 2 — PC → Linux Server

The PC stops being a thing you log into and becomes a thing that just runs. Wipe Windows, install Proxmox VE (a free hypervisor), and run everything as containers and VMs on top. Headless in the corner, managed from the iMac's browser. Hardware cost to start is $0 because you already own the box, the GPU, and the 6TB of storage.

What it runs

A network file share / NAS on the 6TB so the iMac and the Air both offload to it. A media server (Jellyfin, free) with the GPU passed through for transcoding. Tailscale for remote access from anywhere, which cleanly replaces the Windows remote-access setup. Network-wide ad blocking with AdGuard Home or Pi-hole. And your existing desktop-tools stack (yt-dlp, scrapers, the tool server) re-homed into a Linux container where it belongs.

Honest tradeoff: your current Windows tool server has to be migrated to Linux, that's an afternoon of work, not a click. Anything that's genuinely Windows-only can keep running in a Windows VM on Proxmox, so you don't lose it, you just stop booting into it.

Optional add-ons

A small UPS (~$120) so a power blip doesn't corrupt the array, and a cheap 10 GbE NIC (~$50 used) so big transfers between the server and the rest of the network run at backbone speed instead of gigabit.

Phase 3 — The Network (actually using 5 gig)

Reality check: no single device is going to pull all 5 Gbps. The win is aggregate, several things going hard at once, plus a multi-gig backbone so big LAN transfers to the server fly, plus not bottlenecking the WAN at the router. The gateway below does 5 Gbps with IDS/IPS on, which is exactly matched to your plan, no headroom wasted, none missing.

DIY to Cut Cost

Pulling your own Cat6a is the single biggest saver, a low-voltage installer runs $150–$300 per drop and you've got the patience to do it yourself. Buy UniFi direct from store.ui.com (no reseller markup), terminate your own keystones, and source the server's extra NIC and drives off the used market. The PC reuse means Phase 2 is basically free. Skip anything labeled “managed install,” none of this needs it.
