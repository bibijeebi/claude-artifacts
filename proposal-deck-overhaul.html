Proposal #005 — Draft

Deck Overhaul

Re-screen the porch, replace stairs with ramps, fix balusters, and turn the deck into a real outdoor living space.

Est. Cost $500–$1,500+
Difficulty 3/5
Time Multiple weekends
Category Home
Status Draft
This proposal is a stub.

Needs deck measurements, baluster assessment, ramp slope calculations, and screen system selection before full costing.

The Vision

The deck came with screens when we bought the house, but they got beat up and were torn out. The balusters need repair. The stairs are standard but ramps would be better for accessibility (dogs, future kids, general ease). This is a multi-part project that can be phased, but the end goal is a screened-in porch with ramp access that's actually enjoyable to hang out on.

Sub-Projects

A. Re-Screen the Porch

The deck was originally a screened-in porch. The frame structure may still be usable. We looked at three approaches previously: reusing existing frames with new fiberglass screen ($75-125), a Screen Tight system with new base strips and caps ($180-250), or a no-spline tension system ($400-620). Pet-resistant screen is worth considering given the dogs.

Need to check: are the original frame channels still intact, or did they come out with the screens?

Est: $100–$600 depending on system

B. Ramps Instead of Stairs

Replace the existing stairs with ramps on one or two sides of the deck. ADA-compliant slope is 1:12 (1 inch of rise per 12 inches of run), which means if the deck is 3 feet off the ground, each ramp needs to be 36 feet long. That's a lot of run, so a switchback design with a landing may be needed. Local building codes will apply.

This is the most complex sub-project. Need to measure deck height, identify which sides get ramps, and figure out the footprint. Ramps also need railings per code.

Est: $300–$800+ in lumber depending on length

C. Baluster Repair

Several balusters are damaged, loose, or missing. The gaps between existing balusters are wide enough that the dogs and future kids are a concern. This is the simplest sub-project: measure existing baluster dimensions, buy replacement spindles, cut to length, and fasten.

Could also be an opportunity to replace all balusters with a uniform style if the existing ones are a mix of conditions.

Est: $50–$150
Phasing recommendation: Balusters first (safety, cheapest, fastest). Then ramps (biggest quality-of-life improvement). Then screens last (most labor, least urgent). Each sub-project is independent.

What Needs to Happen First

Measure everything: deck height off ground, deck footprint, each screen opening, baluster count and spacing, and available run for ramps. Take photos of the current frame channels (if any remain) for the screen system decision. Check local Wake County building code for ramp and railing requirements.

Decision for Bekah

This can be as small as $50 (just fix the balusters) or as big as $1,500+ (full ramps + screens + repairs). The sub-projects are independent, so we can pick and prioritize. What matters most: safety (balusters), access (ramps), or bug-free outdoor time (screens)?
