Provenance

Who made what

The song · 2024

An original composition, not a parody. The first part is credited to "MusicPerson." osmarks wrote the middle verses around April 17, 2024 and the rest on November 8–9, 2024. osmarks tried LLaMA-3.1-405B base for some lines, then switched to "some contemporary Claude model." The music was generated in Udio. osmarks also keeps a line-by-line interpretation page, which this page draws on for the lyric layer.

Two small disagreements with it. osmarks calls the Shinigami-eyes line "unclear," and here it's read through Death Note. osmarks links the Ilya line to o1-style reasoning; here it stays with the meme's origin in the 2023 OpenAI board fight.

The Opus 5.5 video · Sept 2026

The documented one is John Heibel's. It was built in Claude Code by Claude Opus 5.5, and the whole repository is model-written. The only human direction was to use the Clawd character and give every lyric its own visuals and transitions. Opus planned the shots, wrote a style guide to brief subagents running in parallel, and generated nine chapters.

lyrics timed to 0.1s→STORYBOARD.md→ANIMATION_GUIDE.md → subagents→9 chapters, p5.js + p5.brush→frames in headless Chrome→ffmpeg MP4

This cut

The clip shared by Andy uses the same song and runs the same 156.6 seconds. Its visual system is different: no Clawd, no brushstrokes, and a black HUD look built from diegetic UI, 3D forms and data-viz gags. So it's a separate generation, not the Heibel render.

The post's caption presents it as model-made, but nowhere I could reach documents which model or tool produced it. Treat the "showcase" reading as the obvious one, not a confirmed one.
