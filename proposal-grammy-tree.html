Grammy's Tree, Relit

Grammy is giving us her Balsam Hill tree. The tree is premium, the factory lights are junk. Strip them, relight it with the WS2811 bullet pixels already sitting in garbage bags in the garage, and run it off WLED. Warm white the second it's plugged in, anything else from a phone.

Bottom Line

A free premium tree plus pixels, power supplies, ESP32s and project boxes we already own means the only real cost is one weekend of snipping. New spend is connectors and wire, $15–30. Spending more only buys convenience (a ready-made WLED controller, a fresh power supply). The result beats any store pre-lit tree, because nothing in it is proprietary and every bulb is replaceable.

How It's Wired

One pixel run per tree section, joined at each section seam with a 3-pin pigtail so the tree still comes apart for storage. Power gets re-injected at every seam, which is where the run breaks anyway.

Pixel count depends on the tree. Balsam Hill doesn't publish one per-foot rule, so count after pickup. The working target is roughly the factory bulb count in pixels or a bit under, since pixels are brighter than mini lights. For a 7.5 ft tree that's ballpark 8–12 strings of 50.

Power Math

A 12V, 50-count, 4″-spacing bullet string is rated 15 W, 1.25 A per string (Light-O-Rama spec), about 0.025 A per pixel at full white. Generic bullets run close to that.

Set WLED's automatic brightness limiter (LED settings) to the supply's real amp rating minus 15%. Then even a full-white accident can't overload anything. A tree never runs full white anyway; it looks like a stadium.

Build Steps

  1. Pick up the tree from Kim's unit next weekend. Get the model/height off the box.
  2. Set it up and count factory bulbs on one section to set the pixel target.
  3. Cut the factory strings off. Leave the trunk wiring in place, dead. Don't pull wire out of the pole.
  4. Flash an ESP32 with WLED from install.wled.me in Chrome. Bench-test every pixel string before it goes on the tree; pull dead pixels now, not after it's woven in.
  5. Wire each section as its own run with a pigtail at each seam. Weave from trunk outward along each branch and back, so pixels sit deep, not just on the tips.
  6. Run 12V injection up the trunk to each seam. Fuse the supply output.
  7. In WLED: set LED count and the brightness limiter, build presets (Warm White, Candle, Slow Twinkle, Multicolor), set Warm White as the boot preset. Add it to the WLED phone app.
  8. Take it apart once and put it back together to prove the seams work before December.

What It Unlocks

  • A premium tree that turns on like a normal one: plug in, warm white, done.
  • Phone or voice control. WLED shows up in Alexa and Home Assistant, which ties into the smart-home phases of #023.
  • Repairs are one bulb, not a dead section.
  • Uses up some of the garage pixel stash without touching what the house exterior needs.
