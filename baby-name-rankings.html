Bottom Line

We built a custom web app to pick baby names. It has 458 names across 20 categories. We each vote independently without seeing the other's picks (blind voting with spoiler mode), and the app reveals matches when we both say yes. So far we have 12 mutual favorites, 5 boys and 7 girls. Benny then ran 917 head-to-head comparisons through a Bradley-Terry statistical model to get precise rankings for his top 60 boys and 60 girls. Next step: Bekah does the same, then we combine reports.

What We're Looking For

We started with 458 names sourced from SSA top baby names (2014–2024), then filtered and categorized them based on our preferences.

✓ Classic, timeless names ✓ Must be easy to yell across a yard ✓ Celtic/Scottish heritage names ✓ Nature-inspired names (girls) ✓ Strong, clean sound ✗ Too biblical (Isaac, Abraham, Noah) ✗ Names with cultural baggage (Karen, Chad) ✗ Hard to pronounce or spell ✗ Trendy names that'll age badly ~ Shorter names preferred (soft rule) ~ Some biblical names are fine (Gabriel, Ezra)

The matches reflect these preferences well. Nature names (Hazel, Violet, Lily), Celtic names (Ronan, Beckett), French names (Camille, Eloise), and clean classics (Lucas, Ava, Gabriel).

How We Built This

1. Initial List Building

Claude generated ~500 names across 20 categories, filtered for zero negative cultural connotations.

2. Conversational Triage

Names workshopped live in conversation. Boring names got killed (BIAR), Scottish/Celtic picks added based on Stewart clan heritage. Phonetically broken names purged (Aoife, Caoimhe, Saoirse). Pool stabilized at ~458.

3. Blind Voting App

Built a custom web app with independent blind voting. Each person votes yes/no/maybe without seeing the other's picks. Real-time sync via WebSocket, spoiler toggle to reveal matches. The app has categories, filters, a roulette spinner, and comment threads on each name.

4. Yes/No/Maybe Filter

458 names triaged down to 302 (150 boys, 152 girls) that entered the head-to-head ranker based on yes and maybe votes.

5. Head-to-Head Ranking

917 paired comparisons using a Bradley-Terry statistical model with active learning. Custom keyboard-driven app served the most informative pair each time. Progressive elimination cut to top 60 per gender.

6. Next: Bekah's Rankings

Bekah runs the same head-to-head process independently. Then we combine reports to find convergence, divergence, and discussion candidates.

The Bigger Picture

We're planning for a big family (6–8 kids), which is partly why we're taking the name selection seriously and building out a large pool early. We don't want to burn through all the good names on kid #1 and be stuck scrambling by kid #4.

Having a ranked, organized list of names for both boys and girls means we'll be ready no matter what, and we won't have to make a rushed decision in the delivery room. The app will grow with us, adding new names, re-running brackets, and tracking which names we've "used" as kids arrive.
