Someone opens the request portal on their phone, logs in with Google, searches for a show, and hits "Request." That request goes to Jellyseerr, which tells Radarr (movies) or Sonarr (TV) to find it. They ask Prowlarr to search torrent indexers. When a match is found, qBittorrent downloads it through the VPN so your ISP can't see what's being downloaded. Once complete, Radarr/Sonarr rename and move the file to the proper folder, then notify Jellyfin to scan. Bazarr monitors the library and automatically downloads English subtitles. The content is then streamable from any device, anywhere.

Networking Architecture

Method 1: Cloudflare Tunnel (Admin Tools + Request Portal)

No port forwarding needed

Browser → Cloudflare Edge → Google OAuth → Cloudflare Tunnel → localhost:PORT

All admin services and Jellyseerr go through a Cloudflare Tunnel, a persistent outbound connection from your desktop to Cloudflare. Cloudflare Access sits in front and requires Google login. Only whitelisted email addresses are allowed. Sessions last 30 days.

This method cannot be used for Jellyfin because Cloudflare's TOS prohibits streaming video through their free tunnel service.

Method 2: Caddy Reverse Proxy + Port Forwarding (Jellyfin)

Direct HTTPS with Let's Encrypt

Browser → Public IP:443 → Router → LAN_IP:443 → Caddy → localhost:8096

Jellyfin is accessed via direct port forwarding. Port 443 on your router forwards to Caddy, which handles HTTPS with a real Let's Encrypt certificate and proxies to Jellyfin. No Cloudflare in the middle, so video streaming is unrestricted.

Method 3: Tailscale (P2P Alternative)

Zero-config peer-to-peer WireGuard

Device (Tailscale) → P2P WireGuard tunnel → TAILSCALE_IP:8096

Tailscale creates a peer-to-peer VPN mesh. Access Jellyfin directly at its Tailscale IP with zero bandwidth limits and no port forwarding.

DNS

Domain is managed in Cloudflare. The watch.* subdomain points to your public IP as a DNS-only A record. All other subdomains are CNAMEs pointing to the tunnel.

DDNS

A PowerShell script runs every 5 minutes via Windows Task Scheduler. It checks your current public IP against the Cloudflare DNS A record and updates it via the Cloudflare API if it changed. Only affects the Jellyfin route since tunnel subdomains don't depend on your IP.

Local Network Gotchas

DHCP Reservation: The desktop's MAC address is bound to a fixed LAN IP in the router so port forwarding doesn't break.

Hairpin NAT: Most consumer routers don't support accessing your own public IP from inside the network. Use localhost:8096 directly or add a hosts file override.

Security

Cloudflare Access: A wildcard app on *.yourdomain.com with Google OAuth. Only whitelisted Gmail accounts are authorized.

VPN Binding: qBittorrent is bound to the VPN's WireGuard interface. If the VPN drops, torrents stop. Your real IP is never exposed to torrent peers.

HTTPS Everywhere: Caddy provides Let's Encrypt certs for Jellyfin. Cloudflare provides TLS termination for all tunnel subdomains.

Windows Sleep Disabled: Desktop stays awake so services remain available 24/7.

User Experience

The end user workflow:

Open tv.yourdomain.com → Log in with Google (once/30 days) → Search & Request → Wait for download → Open watch.yourdomain.com → Watch with subtitles

No maintenance required. Everything is automated, runs on boot, and self-updates DNS. New episodes of monitored shows download automatically when available.
