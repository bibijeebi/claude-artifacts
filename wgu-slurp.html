How to Use

1
Log into my.wgu.edu and navigate to a course content page
2
Click the WGU Slurp bookmark in your bookmarks bar
3
If the course code isn't auto-detected, type it (e.g. C715)
4
A toast confirms the page was captured. Move to the next page and repeat.
5
Tell Claude "quiz me on C715" and it pulls your slurped content automatically

Tips

The bookmarklet grabs text from the main content area, skipping nav/footer. It also captures all WGU links on the page for cross-referencing.

Works on any WGU page: course content, pre-assessment results, study guides, module overviews.

Each page is deduplicated by URL, so re-slurping the same page just updates it.
