Overview

What the hell is Seedance 2.0?

Seedance 2.0 is ByteDance's (TikTok's parent company) new AI video generation model. Every other AI video tool works roughly the same way: type a prompt, get a video, hope for the best. Seedance 2.0 is different because it lets you feed it images, videos, audio, AND text all at once, then assign each input a specific role using an @ reference system.

You're not prompting. You're directing. Upload a dance video as motion reference, a photo as your character, an audio file as the soundtrack, and text describing the scene. The model understands what each piece is for and combines them. That's the paradigm shift.

It launched February 10, 2026 via ByteDance's Jimeng/Dreamina platform. The international API is expected to go fully public on February 24 through BytePlus. Right now you can access it early through a few different paths.

Heads Up — Feb 10 Restriction

ByteDance just suspended the ability to upload real human face photos as reference subjects due to privacy concerns. They also added a live verification step (record your own face/voice) before you can create digital avatars. The face-lock character consistency feature is currently restricted.

Getting In

Three ways to access Seedance 2.0

There are 3 paths ranked from easiest to most full-featured. You don't necessarily need the Chinese phone number route.

BytePlus API
Easiest — No Chinese Number

BytePlus is ByteDance's international developer platform. No Chinese phone number needed, just a regular email signup. Seedance 1.5 Pro is already live with 2M free tokens. Seedance 2.0 API expected Feb 24.

Go to byteplus.com and create an account with email
Navigate to ModelArk in the console
Generate an API key, start calling the Seedance endpoint

The catch: this is API/developer-oriented, not a nice visual GUI. Best if you're comfortable with code or want to integrate it into a workflow. Third-party wrappers like Replicate, Together AI, Fal.ai will also have Seedance 2.0 after the 24th with friendlier interfaces.

Little Skylark App
Free Tier — Mobile App

Search for "小云雀" (Xiao Yunque) in your app store. ByteDance's lighter creative app that's currently in a growth phase, offering free Seedance 2.0 generations with zero point deduction. You get 3 free gens on first login plus 120 daily points.

Download Little Skylark from App Store or Google Play
Create account and log in
Go to video generation tab, manually select Seedance 2.0 from dropdown (defaults to older model)

Simpler interface than Jimeng but has the core text-to-video and image-to-video features. May still require Chinese account verification depending on region.

Jimeng (Dreamina)
Full Features — Chinese Number Required

The full experience with all multimodal features: the @ reference system, multi-image/video/audio input, "All-Round Reference" director mode. This is where the magic from the demos lives. Requires a Douyin (Chinese TikTok) account.

Get a Chinese +86 phone number via SMS verification service (see guide below)
Create a Douyin account using that number (browser or app)
Go to jimeng.jianying.com and sign in with Douyin credentials
Navigate to Generate → Video Generate → Seedance 2.0

The UI is in Chinese, so use Chrome's built-in page translator. Free tier gets a few daily gens. The Standard Membership at ~69 RMB/month (~$9.50 USD) unlocks Fast Mode, commercial licensing, and the full director-level features.

Bonus — Volcengine Playground

ByteDance's cloud platform at console.volcengine.com has a Playground where you can select "Doubao-Seedance-2.0" under Vision models. New users get 8 free 15-second HD video generations. Nice for quick testing without committing to anything.

The Phone Number Problem

Getting a Chinese +86 number

If you're going the Jimeng route, you need a Chinese phone number because Douyin requires +86 SMS verification and Jimeng uses Douyin as its login provider. No Douyin account = no Jimeng access. The entire auth chain is Chinese-number-gated.

How it works: SMS verification services maintain pools of real Chinese SIM cards (not VoIP). You rent one temporarily, the service receives the SMS on the physical SIM, and displays the verification code to you on a web dashboard. You never touch a physical phone. The number gets recycled after you're done.

There are two tiers of services:

Recommended — Paid Services ($0.50-2.00)

You create an account, deposit $1-5, select "Douyin/TikTok" as the service and "China" as the country, get a private number assigned just to you for ~20 minutes. Code arrives in your dashboard. Much more reliable than free options.

Core Concept

The @ reference system

This is what makes Seedance 2.0 fundamentally different from every other AI video tool. When you upload files, they get auto-labeled: @Image1, @Image2, @Video1, @Audio1, etc. You reference them in your prompt to assign each file a specific role.

Think of it like casting a film. You're telling the AI: "this file is the actor, this file is the cinematographer's reel, this file is the soundtrack." Each @ reference has a purpose.

🎬

Motion / Camera Reference

"Reference @Video1 for camera movement" — steals the cinematography from any video and applies it to your scene

👤

Character Reference

"@Image1 is the main character" — locks face identity throughout the video (currently restricted for real faces)

🎨

Style Reference

"Use @Image2 for visual style" — applies color grading, lighting, aesthetic from a reference image

🎵

Audio Reference

"Use @Audio1 for background music" — syncs the generated video to your audio track

🏠

Environment Reference

"@Image3 as the setting" — uses an image as the scene/location for your video

Prompt Craft

Example prompts

The key is being explicit about what each @ reference controls. Here are real prompt patterns:

Camera + Character + Setting
Reference @Image1 for the man's appearance in @Image2's elevator setting. Fully replicate @Video1's camera movements and the protagonist's facial expressions. Hitchcock zoom when startled, then several orbit shots inside the elevator. Doors open, tracking shot following him out.
Ad Creative Replication
Replace the person in @Video1 with the girl in @Image1. Reference @Video1's camera work and transitions. Keep the same editing rhythm and pacing.
Motion Transfer
@Image1 performs the dance from @Video1. Match the choreography exactly. Use @Audio1 for background music. Beat-synced editing.
Multi-Shot Storytelling
Shot 1 is a wide view of the city at sunset. Shot 2 is a close-up of the character from @Image1 looking out a window. Shot 3 is a tracking shot following them down a hallway. Consistent character, smooth transitions between scenes.
Video Extension
Extend @Video1 by 15 seconds. The character walks through the door into a sunlit garden. Wide establishing shot, then slow push-in to a close-up. Ambient nature sounds.
One-Take Continuity
@Image1 through @Image5, one continuous tracking shot following a runner up stairs, through corridors, onto the roof, ending with an overhead view of the city. No cuts. One continuous take.
Capabilities

What it actually does

🎥

Motion + Camera Replication

Upload a reference video and Seedance extracts choreography, camera techniques (dolly, tracking, crane, handheld), editing rhythm, and specific moves (Hitchcock zooms, whip pans, orbit shots). You're stealing cinematography from any video.

🔄

Creative Template Replication

Find an ad format, transition effect, or editing style you like. Upload it as reference, swap in your own product/character. One-click recreation of trending content. Massive for ad scaling.

➕

Video Extension + Continuation

Take an existing clip and extend it with smooth continuity. Not just "generate more" but "keep filming" with shot-to-shot coherence.

✂️

Video Editing

Modify existing videos without regenerating: character replacement, add/remove elements, apply new styles, change narrative direction. Preserves the original motion and composition.

🔊

Audio Sync + Lip Sync

Generates realistic lip-sync matched to mouth movements in multiple languages. Environmental sounds (wind, rain, traffic) based on scene content. Sound effects matched to on-screen actions. Music that follows visual rhythm.

🎶

Beat-Synced Editing

Music video style content that actually hits the beats. Outfit changes, scene transitions, and camera moves timed to the music. Upload audio reference and the visual editing syncs to it.

📖

Multi-Shot Storytelling

Describe a sequence of shots in one prompt. The AI understands they belong to the same story. Multi-camera narrative flow with synced audio, consistent characters, smooth transitions.

Get Good

Pro tips

📸

High-Quality References

If @Image1 is blurry, your video will be blurry. Use 2K or 4K images. The AI needs clean source material to work with.

🎯

Be Explicit About References

"Reference @Video1's camera movement" hits way harder than just mentioning the file. Tell the model exactly what you want from each reference.

🔀

Combine Video + Image Tags

Upload a photo as @Image1, a dance video as @Video1, prompt: "@Image1 performs the dance from @Video1." Perfect motion transfer to a custom character. This is the power move.

🔁

Iterate Small Changes

Don't rewrite your whole prompt if you don't like a result. Change one word or swap one reference file. Generation is fast enough to try 10 versions in 5 minutes.

📝

Edit vs. Reference

Make clear whether you want to EDIT an existing video (modify it) or use it as a REFERENCE for something new (copy its style/motion). Different intent, different results.

🌐

Chrome Translate

Jimeng is in Chinese. Right-click → "Translate to English" in Chrome. Works fine for navigation. The prompt input box accepts English text.
