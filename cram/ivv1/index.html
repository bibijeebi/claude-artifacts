Absolute references are the #1 trip hazard. Memorize the $ rule: the $ locks whatever comes AFTER it. Drag down → lock row. Drag across → lock column. Both → lock both.

Cell References TIER 1 KILLER

If you miss this concept on the MC question, you fail. If you get it right, everything else is mechanical.

The Rule

The $ in a cell reference locks whatever comes right after it.

ReferenceColumn letterRow numberWhen to use
A1RelativeRelativeDefault — both shift when copied
$A1LOCKEDRelativeDragging across, column should stay put
A$1RelativeLOCKEDDragging down, row should stay put
$A$1LOCKEDLOCKEDPointing to a fixed cell from anywhere
MNEMONIC "Dollar locks what comes after." Read the reference left-to-right. Column letter first, then row number. Any $ you see locks the thing immediately to its right.

Drag Direction Rule

DRAGGING DOWN ↓

Rows change. Columns don't. To keep a row fixed: A$1 is enough. $A$1 also works.

DRAGGING ACROSS →

Columns change. Rows don't. To keep a column fixed: $A1 is enough. $A$1 also works.

DRAGGING BOTH ↘

Both shift. If you need a cell truly locked, use $A$1. Otherwise row-lock or col-lock based on intent.

The Washington Growth Rate Trap

State growth rate in cell C2 (1.5%). County 2018 populations in column F, rows 5-43. Compute 2019 simple population in G5 and drag DOWN:

WRONG
=F5*(1+C2)
C2 shifts to C3, C4... as you drag. You'd multiply by whatever's in those cells (probably blank = 0).
RIGHT
=F5*(1+$C$2)
$C$2 stays locked. F5 becomes F6, F7... as you drag. Each county gets the state rate applied.
OA TRAP The MC question will show 4 options: C2, $C2, C$2, $C$2. Since you're dragging DOWN only, any of $C$2 or C$2 works. The fully-relative C2 always fails. $C2 only helps for horizontal drag.

Individual Growth vs. State Growth

If each county has its OWN growth rate in column G (G5-G43), and you want individual 2019 in column H:

=F5*(1+G5)   // Both relative, each row uses its own rate — correct
=F5*(1+$C$2) // Uses STATE rate for every row — wrong for "individual"
=F5*(1+$G$5) // Uses ONLY row 5's rate for every row — wrong

F4 Toggle (Mac = Fn+F4 or Cmd+T)

While editing a formula, put your cursor on a reference and press F4. Cycles through:

A1  →  $A$1  →  A$1  →  $A1  →  A1  // back to start

COUNTIF / SUMIF / AVERAGEIF TIER 1

Conditional aggregation. Syntax pattern is identical across all three.

The Pattern

COUNTIF(range, criteria)
SUMIF(criteria_range, criteria, sum_range)       // sum_range is LAST
AVERAGEIF(criteria_range, criteria, average_range)
MNEMONIC "Check first, then sum." The range you're checking always comes FIRST. The range you're summing/averaging comes LAST. In the middle: what to check for.

Criteria Syntax

CriteriaWrite it asExample
Equals text"Metro"=COUNTIF(B:B, "Metro")
Equals number100 or "100"=COUNTIF(A:A, 100)
Greater than">100" (quotes!)=COUNTIF(F:F, ">10000")
Less than or equal"<=5%"=COUNTIF(G:G, "<=0.05")
Wildcards"North*"Counts "North", "Northwest", "North Carolina", etc.
TRAP Comparison operators MUST go inside the quotes with the value. COUNTIF(F:F, >10000) errors. COUNTIF(F:F, ">10000") works. No space between operator and value.

Washington Examples

// How many Metro counties?
=COUNTIF(B2:B40, "Metro")

// Total population of Northeast region
=SUMIF(C2:C40, "Northeast", F2:F40)

// Average unemployment in Southeast
=AVERAGEIF(C2:C40, "Southeast", H2:H40)

// Count counties with population > 100,000
=COUNTIF(F2:F40, ">100000")

IF / Nested IF / VLOOKUP / XLOOKUP TIER 2

Basic IF

=IF(condition, value_if_true, value_if_false)

// Examples
=IF(A1>=60, "Pass", "Fail")
=IF(E2="Metro", F2*1.1, F2)          // 10% bump for Metro

Nested IF (letter grades)

Evaluate the highest threshold first, then fall through:

=IF(A1>=90, "A",
   IF(A1>=80, "B",
     IF(A1>=70, "C",
       IF(A1>=60, "D", "F"))))
COMMON MISTAKE Writing nested IFs bottom-up (70 → 80 → 90). A score of 95 would match "≥70" first and return "C". Always start with the highest threshold.

IFS (Excel 2019+, cleaner)

=IFS(A1>=90, "A",
     A1>=80, "B",
     A1>=70, "C",
     A1>=60, "D",
     TRUE, "F")             // TRUE = catch-all

Logical helpers

=AND(A1>50, B1<100)    // TRUE only if both
=OR(A1="Metro", A1="Urban")  // TRUE if either
=NOT(A1="Metro")           // TRUE if NOT Metro

// Combine with IF
=IF(AND(A1>50, B1<100), "Yes", "No")

VLOOKUP

=VLOOKUP(lookup_value, table_array, col_index_num, [range_lookup])
                                                       // FALSE = exact
                                                       // TRUE = approximate

// Look up "King" in column A of Sheet2, return the value in column C
=VLOOKUP("King", Sheet2!A:C, 3, FALSE)
VLOOKUP LIMITATIONS Lookup value MUST be in the FIRST column of the table_array. You CANNOT return values from columns to the LEFT. If columns are inserted, your col_index_num breaks silently.

XLOOKUP (the modern replacement)

=XLOOKUP(lookup_value, lookup_array, return_array, [if_not_found])

// Example — returns "Not found" instead of #N/A
=XLOOKUP("King", A:A, C:C, "Not found")
WHY XLOOKUP BEATS VLOOKUP Works in any direction (left OR right). No column index to get wrong. Built-in not-found handling. Survives column inserts. When available, use it.

INDEX/MATCH (legacy bidirectional)

=INDEX(return_range, MATCH(lookup_value, lookup_range, 0))

// Look up "King" in column A, return col C value (works left-to-right too)
=INDEX(C:C, MATCH("King", A:A, 0))

PivotTables TIER 1 READING · TIER 2 CREATION

The PA gives you pre-built pivots to read. The OA may also ask you to build one.

Four Areas

AreaWhat goes hereExample
RowsCategory to group byRegion
ColumnsSecondary grouping (optional)Metro / Non-Metro
ValuesNumeric aggregationSum of Population, Count of County, Avg of Unemployment
FiltersWhole-pivot filterYear = 2018

Reading a Pivot (PA pattern)

The PA shows a pre-built pivot and asks questions like:

Q: HOW MANY COUNTIES ARE IN SOUTH PUGET SOUND? Pivot has Region in Rows, Count of County in Values. Find the "South Puget Sound" row. Read the number in the Count column. That's the answer.
Q: HOW MANY METRO COUNTIES IN THE NORTHEAST REGION? Pivot has Region in Rows, Metro/Non-Metro in Columns, Count of County in Values. Find the intersection of "Northeast" row and "Metro" column. Read the number.
Q: WHICH REGION HAS THE HIGHEST AVG UNEMPLOYMENT? Pivot has Region in Rows, Average of Unemployment Rate in Values. Scan the values column for the largest number. Read the region on that row.

Building a Pivot (Barney-style)

  1. Click anywhere in your data table.
  2. Insert tab → PivotTable.
  3. Confirm the data range, pick "New Worksheet" or existing (PA uses existing).
  4. In the PivotTable Field List on the right, drag field names into the four areas.
  5. To change Sum → Average: right-click a cell in Values area → Summarize Values By → Average.
  6. If source data changes: right-click pivot → Refresh.

Value Field Settings

Right-click any value in the pivot → Summarize Values By. Common choices:

Sum       // Add the numbers
Count     // How many records
Average   // Arithmetic mean
Max/Min   // Largest/smallest
Product   // Multiply all
TRAP Default aggregation for text fields is COUNT. For numeric fields it's SUM. If you need Count of numeric values (e.g. "how many counties"), you might need to manually switch from Sum to Count.

Excel Tables TIER 2

Create a Table

  1. Select your data range.
  2. Press Cmd+T (Mac) or Ctrl+T (Win).
  3. Check "My table has headers" if row 1 is field names. Click OK.

Structured References

Inside a Table named Counties, formulas can use column names instead of cell coords:

=[@Population]*[@GrowthRate]   // "this row's" values
=SUM(Counties[Population])     // entire column
=Counties[@[Population]:[Region]] // range across columns
MNEMONIC "At-sign = this row." [@ColName] means "the value of ColName in the current row." Without the @, it's the whole column.

Calculated Column Auto-Fill

Type a formula in one cell of a Table column. Excel auto-fills the formula down every row. This works only inside Tables, not regular ranges.

Total Row

  1. Click inside the Table.
  2. Table Design tab → check "Total Row".
  3. A row appears at the bottom. Click any cell in the Total Row → dropdown appears with Sum / Average / Count / Max / Min / StDev / Var.

Sort & Filter in Tables

Tables get dropdown arrows in their headers automatically. Click the arrow → Sort A→Z, sort largest first, filter by specific values, text filters, number filters, etc.

Date Functions TIER 2

The Key Functions

=TODAY()              // today's date (volatile)
=NOW()                // today's date + current time

=YEAR(A1)             // 2024 from 2024-03-15
=MONTH(A1)            // 3 (number 1-12)
=DAY(A1)              // 15 (day of month)

=DATE(2024, 3, 15)    // build a date from parts

=YEAR(TODAY())-YEAR(A1)       // years elapsed
=TODAY()-A1                   // days elapsed
HOW DATES WORK Excel stores dates as numbers. Day 1 = Jan 1, 1900. Today (2026-04-17) is ~46,130. Subtracting two dates gives the difference in days. Add/subtract like any numbers.

Text Functions TIER 3

=LEFT("Washington", 4)      // "Wash"
=RIGHT("County-101", 3)     // "101"
=MID("Metro-King-50", 7, 4) // "King" (start at 7, take 4)
=LEN("King County")         // 11 (includes spaces)
=TRIM("  K   C  ")          // "K C" (collapse all spaces)

=UPPER("wash")              // "WASH"
=LOWER("WASH")              // "wash"
=PROPER("king county")      // "King County"

// Concatenation: & operator or CONCATENATE() — both work
=A1 & " - " & B1          // "King - Metro"
=CONCATENATE(A1, " - ", B1)

Charts TIER 2

Decision Tree

Comparing categories (counties, regions, products)? → Column / Bar chart
Trend over time (monthly sales, population by year)? → Line chart
Parts of a whole (regional shares of state pop)? → Pie chart (keep to ≤5 slices)
Correlation between two numbers (poverty % vs unemployment)? → Scatter plot (XY)
Multi-category stacked composition? → Stacked column / area

Create a Chart (Barney-style)

  1. Select your data (headers + values).
  2. Insert tab → pick chart type from the Charts group.
  3. Chart appears; Excel puts it near the data.
  4. Chart Design tab appears (only when chart selected):
    • Add Chart Element → Title, Axis Titles, Legend, Data Labels, Gridlines
    • Change Chart Type — switch column↔line↔bar without rebuilding
    • Switch Row/Column — transpose what's on the X axis
    • Select Data — fix the data range
PIE CHART TRAP If the question asks you to "show proportions" and gives you 15+ categories, pie is the WRONG answer. Column or bar chart. Pies lose readability past 5-6 slices.

Sort & Filter TIER 2

Sort

  1. Click any cell in your data.
  2. Data tab → Sort.
  3. Pick Sort By column, order (A→Z / Z→A / Smallest→Largest / etc.).
  4. Add Level for multi-key sort (sort by Region, then by Population within each Region).

Filter

  1. Click any cell in your data.
  2. Data tab → Filter (or Cmd+Shift+L).
  3. Dropdown arrows appear on each header.
  4. Click the arrow on a column → uncheck values to hide, or use Text Filters / Number Filters for rules.
FILTER ≠ DELETE Filtering hides rows, it doesn't remove them. Clear the filter to see everything again.

ErrorMeaningCommon cause

#REF!Invalid referenceDeleted a row/column that a formula was pointing at.
#VALUE!Wrong data typeTried to multiply text by a number, SUM over a mixed range, etc.
#N/ANot availableVLOOKUP/XLOOKUP found no match. Wrap in IFERROR.
#NAME?Unknown nameTypo in function name (=SUUM(...)) or undefined named range.
#NUM!Invalid numberBad numeric argument (sqrt of negative, iteration that won't converge).
#NULL!Bad range operatorSpace instead of comma/colon between ranges that don't intersect.

Graceful Error Handling

=IFERROR(formula, value_if_error)
=IFNA(formula, value_if_na)         // #N/A only

// Example
=IFERROR(VLOOKUP(A1, B:D, 3, FALSE), "Not found")

Function Cheat Sheet ONE-PAGER

Aggregations

=SUM(range)            // total
=AVERAGE(range)        // mean — ignores blanks and text
=COUNT(range)          // count of NUMERIC cells only
=COUNTA(range)         // count of ANY non-empty cells
=COUNTBLANK(range)     // count of empty cells
=MAX(range)            // largest
=MIN(range)            // smallest
=MEDIAN(range)         // middle value
=ROUND(number, digits)

Conditional

=COUNTIF(range, criteria)
=SUMIF(check_range, criteria, sum_range)
=AVERAGEIF(check_range, criteria, avg_range)
=COUNTIFS(range1, crit1, range2, crit2, ...)   // multiple criteria
=SUMIFS(sum_range, range1, crit1, range2, crit2)
=IF(test, if_true, if_false)
=IFS(cond1, val1, cond2, val2, ..., TRUE, default)
=AND() / =OR() / =NOT()
=IFERROR(formula, on_error)

Lookup

=VLOOKUP(value, table, col_num, FALSE)
=HLOOKUP(value, table, row_num, FALSE)
=XLOOKUP(value, lookup_array, return_array, if_not_found)
=INDEX(range, row, col)
=MATCH(value, range, 0)

Date

=TODAY() / =NOW()
=YEAR() / =MONTH() / =DAY()
=DATE(year, month, day)
=DATEDIF(start, end, "Y"|"M"|"D")

Text

=LEFT() / =RIGHT() / =MID()
=LEN() / =TRIM()
=UPPER() / =LOWER() / =PROPER()
=CONCATENATE() or use & operator
