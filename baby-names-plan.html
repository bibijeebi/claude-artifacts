How We Built This

A multi-stage pipeline from blank slate to ranked list.

1. Initial List Building

Claude generated ~500 names across 20 categories (Classic, Modern-strong, Scottish/Celtic, French, Italian, Hebrew/Biblical, Greek, Dutch, German/Nordic, etc.) filtered for zero negative cultural connotations.

2. Conversational Triage

Names workshopped live in conversation. Boring names got killed (BIAR), Scottish/Celtic picks added based on Stewart clan heritage. Phonetically broken names purged (Aoife, Caoimhe, Saoirse). Pool stabilized at ~458.

3. Blind Voting App

Built a custom web app with independent blind voting. Each person votes yes/no/maybe without seeing the other's picks. Real-time sync via WebSocket, spoiler toggle to reveal matches. 12 mutual matches identified so far.

4. Yes/No/Maybe Filter

458 names triaged down to 302 (150 boys, 152 girls) that entered the head-to-head ranker based on yes and maybe votes.

5. Paired Comparisons

917 head-to-head matchups using a Bradley-Terry statistical model with active learning. Custom keyboard-driven app served the most informative pair each time, prioritizing close matchups and coverage.

6. Progressive Elimination

At 5+ avg comparisons per name, the bottom 60% was automatically eliminated, focusing remaining effort on the top 60 per gender. Tier boundaries determined by natural gaps in ratings (>60 point gap = new tier).

How to Read the Ratings
1000 is average. Every 100 points is roughly a 65% expected win rate over a name 100 points lower. Within a tier, exact ordering is soft. The tier boundaries are where the real signal is. Names marked ~ were "maybe" during initial triage. Names marked ❤ are mutual matches with Bekah.
What's Next
Bekah runs the same head-to-head ranking process independently. Once both reports exist, we combine them to find convergence (names we both rank highly), divergence (one loves, one doesn't), and discussion candidates (close for both). Planning for 6–8 kids, so we're building a deep bench, not just picking one name.
