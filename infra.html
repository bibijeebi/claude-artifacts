What this is

Every Claude AI conversation from August 2023 through February 2026, exported, chunked, embedded, summarized, tagged, scored, and made searchable through a Model Context Protocol server. Claude (and Deep Research) can query this system in real-time to find patterns, trace arcs, and surface connections across thousands of conversations.

The system lives entirely on Cloudflare: D1 for structured data, Vectorize for embeddings, Workers for the MCP server, KV for caching. External APIs: Voyage AI for embeddings and reranking, Anthropic for HyDE query expansion.

messages

Every message in every conversation. Sender, text, position. Also indexed in FTS5 for keyword search.

chunks

Each conversation is sliced into overlapping ~1,500-character windows. One summary chunk (AI-generated overview) plus N conversation chunks (raw message text). Each chunk has a vector_id mapping to its embedding in Vectorize.

Vectorize

45,739 embeddings via voyage-4-large (1024 dimensions, cosine similarity). Cloudflare's native vector database. Sub-100ms query times.

The enrichment pipeline

Five layers, each built on the last. All AI enrichment uses Claude Sonnet 4.6 via the Anthropic Batch API (50% off).

Layer 1
Raw ingest
Conversations, messages, chunks, FTS5 index, vector embeddings
Layer 2
Summaries
97% coverage. 5,914 Sonnet-generated 2-4 sentence overviews
Layer 3
30 tags
99% coverage. Programming, homesteading, philosophy, etc.
Layer 4
Scoring
99.5% coverage. Insight, impact, depth (0-10) + transition type

Total enrichment cost: ~$12 across three Batch API runs. Each run: pull data from D1, submit batch to Anthropic, poll results, batch-write back to D1 using CASE WHEN bulk updates.

The search pipeline

When hybrid_search receives a query, this is what happens:

1
HyDE expansion
If the query is 7+ words, Claude Opus generates a hypothetical conversation snippet that might match the query. This fake text gets embedded instead of the raw query, dramatically improving recall for abstract or metaphorical searches.
2
Two parallel searches
The HyDE text becomes a 1024-dim vector via Voyage AI and queries Vectorize (cosine similarity, top 60). Simultaneously, FTS5 keyword search runs against the messages table (BM25 ranking, top 60).
3
Reciprocal Rank Fusion
Both result sets merge using RRF (k=60). Conversations appearing in both semantic AND keyword results get boosted scores. Results deduplicate to one per conversation.
4
Tag + score filters
Optional filters narrow results: tags="philosophy-consciousness", min_insight=7, transition_type="breakthrough". This is what makes Deep Research's targeted queries possible.
5
Cross-encoder reranking
Voyage rerank-2.5 re-scores candidates by looking at query-document pairs jointly. More accurate than cosine similarity. Returns final ranked results with relevance scores from 0.0 to 1.0.

Deep Research test query

This prompt is designed to exercise the new v3.2 scoring filters. Paste it into a new Claude chat with Research enabled and the Chat History connector active.

Using my Chat History connector (13 tools including list_scores), conduct a longitudinal analysis of my 6,000+ Claude conversations from Aug 2023 to Feb 2026.

Start by calling list_scores with sort_by="insight_score" min_score=5 to find my highest-insight conversations. Also call list_scores with transition_type="breakthrough,decision,milestone" to map every inflection point. Call stats and list_tags for corpus overview.

Then investigate:

1. Builder arc: browse_conversations tags="programming,dev-tools,nix-nixos,nushell,web-dev" transition_type="milestone,exploration" sort="oldest" — trace the technical evolution from first code to deploying MCP servers. For each milestone found, use get_conversation to read the actual inflection moment.

2. Homesteader arc: browse_conversations tags="homesteading,hunting-fishing,gardening,cooking-food,outdoors-skills,firearms" transition_type="exploration,milestone" sort="oldest" — trace from suburban curiosity to self-sufficiency.

3. Thinker arc: hybrid_search query="consciousness identity self-realization" tags="philosophy-consciousness" min_insight=5 — find the conversations where I did genuine original thinking, not homework. Use get_conversation on the breakthroughs.

4. Family arc: hybrid_search query="vasectomy reversal baby names wedding Bekah marriage" tags="relationships-family,health-medical" transition_type="decision" — map every decision point.

5. Cross-domain: hybrid_search query="applied thinking from one domain to a completely different one" min_insight=4 — find where engineering thinking colonized philosophy or homesteading skills transferred to tech.

6. Meta-pattern: What does the scoring distribution itself reveal? 79% routine, 19% exploration, 2% decision, 0.3% milestone, 0.03% breakthrough. What does it mean that only 2 conversations in 6,098 scored as breakthroughs? What's the operating system underneath?

For EVERY arc: explain WHY transitions happened, not just WHEN. A timeline is not analysis. Every section needs a thesis.

CRITICAL: This dataset covers ONLY Claude conversations. Gaps in usage likely mean I was using ChatGPT, Grok, or Gemini. Don't fabricate narratives about quiet periods.
