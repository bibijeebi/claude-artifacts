How Claude Deploys

Static Pages

Push HTML to GitHub API (bibijeebi/claude-artifacts) → Cloudflare Pages auto-builds → live at niggerfaggot.club/filename.html. Requires base64 content + SHA for updates.

Workers

PUT /workers/scripts/{name} via CF API with multipart form (metadata JSON + JS module). No wrangler CLI. Use curl -sk (skip TLS verify).

Images

Generate via claude-deploy /generate-image (async Gemini, ~15s) → download → process with ImageMagick → upload to R2 → reference URL in HTML. Or: image_search (free) → download → upload to R2.

Desktop Ops

Hit tools.niggerfaggot.club for YouTube downloads, browser automation, reverse image search, shell commands, file management on the Windows machine.
