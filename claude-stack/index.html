The Secret Sauce

Why This Actually Works

🔑

Stored Credentials

API tokens live in Claude's memory system, not hardcoded. Each session has access to the same keys without re-entering them.

🛠️

Worker as Middleware

Claude's sandbox has TLS quirks. The Cloudflare Worker acts as a trusted proxy, making API calls from Cloudflare's infrastructure.

⚡

Git-Triggered Deploys

No complex CI/CD config. Push to repo → Cloudflare Pages detects the commit → builds and deploys automatically. Zero config.

How to Build This Yourself

The Setup (One-Time)

1. Create a Cloudflare Worker

Build a simple proxy that handles R2 uploads, D1 queries, and any other APIs you need. Add auth so only Claude can use it.

2. Connect GitHub to Pages

Create a repo for artifacts. Connect it to Cloudflare Pages with no build command—it just serves static files from the repo root.

3. Save Tokens to Memory

Tell Claude to remember the worker URL, auth key, GitHub token, and repo name. These persist across all future sessions.

4. Define the Workflow

Add a memory note explaining when to use artifacts vs. deploy. Now Claude knows your intent from context.
