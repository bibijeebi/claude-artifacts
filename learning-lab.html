Phase 1

System Literacy

Before you write code, get comfortable in the machine. This separates "I can follow a tutorial" from "I can figure things out."

Filesystem Navigation

Most people are scared of their own filesystem. Get un-scared. Everything below is Nushell:

nu
# Where am I, what's here
ls | sort-by size -r
ls **/* | where type == file | sort-by size -r | first 20

# Finding things
fd "*.log"                    # files by name/glob
fd -e py -e js                # by extension
rg "password" .               # text in files (recursive, fast)
rg -l "TODO" --type py        # which Python files have TODOs

# Bulk operations
ls *.jpg | each { |f| mv $f.name $"photos/($f.name)" }
ls *.txt | enumerate | each { |e|
    mv $e.item.name $"($e.index | fill -a r -w 3 -c '0').txt"
}

PowerShell Read Literacy

You won't use PowerShell daily, but you need to read it because every Windows tutorial and Stack Overflow answer is written in it. Here's the decoder ring:

powershell
# Cmdlets follow Verb-Noun pattern
Get-Process          # = ps in Nu
Get-ChildItem        # = ls
Set-Location         # = cd
Get-Content          # = open (text files)
Where-Object         # = where
ForEach-Object       # = each

# $_ is "current pipeline item" (like |row| in Nu)
Get-Process | Where-Object { $_.CPU -gt 10 } | Select-Object Name, CPU
Concepts to Recognize

COM objects — how Windows apps expose their internals to automation. New-Object -ComObject Excel.Application lets you script Excel directly.

WMI/CIM — a system-info database. Get-CimInstance Win32_Processor queries everything Windows knows about your CPU.

Registry — Windows' giant config file. HKLM:\ is machine-wide, HKCU:\ is per-user.

.NET calls — [System.IO.File]::ReadAllText("file.txt") is calling .NET directly. PowerShell is basically a .NET REPL that happens to be a shell.

You don't need to memorize any of this. You need to recognize it when you see it.

Phase 2

AI-Assisted Shell Work

This is the actual game-changer. AI in the terminal isn't a gimmick, it's a fundamentally different way to learn and work.

Claude Code

The most powerful option. It reads files, runs commands, edits code, and chains operations autonomously:

shell
# Just talk to it
claude "find all Python files that import requests and list them"
claude "explain what this PowerShell script does"
claude "write a script that monitors this folder for new CSVs and summarizes them"

# Interactive mode for longer sessions
claude
# Now Claude can see your filesystem, run commands, iterate on code

# Pipe data through it
cat weird_log.txt | claude "parse this and extract all error messages with timestamps"

It's not autocomplete. It's a pair programmer that can do things on the system. Use it to explore unfamiliar codebases, debug errors, automate repetitive tasks, and learn by having it explain and then quiz you.

aichat (sigoden/aichat)

Lighter weight, perfect for quick questions and piping data through AI:

shell
# Quick questions
aichat "what does the -R flag do in chmod"

# Pipe data through AI
cat error.log | aichat "summarize these errors and suggest fixes"
ls -la | aichat "which of these files are suspiciously large"

# Shell integration - generates commands for you
aichat -r shell "find all files modified in the last 24 hours larger than 10MB"

# Code generation
aichat -r code "python function that takes a CSV and returns summary stats"
The Learning Loop

Encounter something you don't understand (a script, an error, a concept). Ask AI in the terminal — don't context-switch to a browser. Try it immediately in a REPL. Break it on purpose, ask AI about the errors. Build something small with it, even 10 lines. Commit it.

The feedback loop is seconds, not minutes of Googling. That changes everything.

Build Your Own AI Shell Tools

Once you're comfortable, start building AI-powered utilities. A text summarizer in 8 lines:

python
#!/usr/bin/env -S uv run --with httpx,anthropic
"""Pipe anything to this and get a summary."""
import sys, anthropic

text = sys.stdin.read()
msg = anthropic.Anthropic().messages.create(
    model="claude-sonnet-4-20250514",
    max_tokens=1024,
    messages=[{"role": "user", "content": f"Summarize this concisely:\n\n{text}"}]
)
print(msg.content[0].text)

Save as summarize.py. Now: cat giant_report.txt | python summarize.py. From here, build a commit message generator, a code reviewer, a log analyzer. Each one is 10-20 lines.

Phase 4

Math from the Terminal

Not a prerequisite, but a force multiplier. Python makes abstract math tangible.

python
# SymPy: a complete CAS, free, in your terminal
from sympy import *
x = Symbol('x')

solve(x**2 - 5*x + 6, x)           # [2, 3]
diff(sin(x) * exp(x), x)           # derivative
integrate(1/(1 + x**2), x)          # arctan(x)
series(exp(x), x, 0, 6)            # Taylor series

# Learn probability by simulation (the best way)
import random
wins = sum(random.choice([0,1,2]) != random.choice([0,1,2]) for _ in range(100000))
print(f"Monty Hall switch wins {wins/1000:.1f}% of the time")  # ~66.7%
Where to Practice

Project Euler is perfect for downtime. Bite-sized math+code puzzles, hundreds of them, escalating difficulty. Problem 1 takes 5 minutes. Problem 50 takes an hour. Problem 500 takes days.
