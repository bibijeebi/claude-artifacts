01 · The map

Two layers, one toolkit

Propositional logic

P → Qmodus ponensmodus tollens

Whole statements as atoms, glued with →, ∧, ∨, ¬. No quantifiers. This is where the valid and invalid argument forms live, and it covers the bulk of LSAT conditional reasoning.

Predicate logic

∀x(Px→Qx)∃x(Px∧Qx)

Cracks statements open with quantifiers. "All A are B" and "Some A are B" is Aristotle's categorical logic wearing modern notation. On the test this becomes the all/most/some hierarchy.

02 · The four forms

Two pay rent, two are traps

A huge share of Flaw and Parallel Reasoning questions are these four shapes in costume. Learn the silhouettes.

Valid

Modus ponens

affirm the antecedent
P → Q P ∴ Q

If it's a dog, it barks. It's a dog. So it barks. Boring, bulletproof.

Valid

Modus tollens

deny the consequent · the contrapositive move
P → Q ¬Q ∴ ¬P

If it's a dog, it barks. No barking. So not a dog. The single most tested valid move.

Flawed

Affirming the consequent

mistakes Q for proof of P
P → Q Q ∴ P ✗

If it's a dog, it barks. It barks. "So it's a dog." Seals bark. Confuses sufficient with necessary.

Flawed

Denying the antecedent

mistakes ¬P for proof of ¬Q
P → Q ¬P ∴ ¬Q ✗

If it's a dog, it barks. Not a dog. "So no barking." The seal disagrees again.

03 · Trigger words

Translation is the real skill

Nobody writes ∀x under time pressure. High scorers translate English triggers into arrows automatically. Drill these until they're reflex.

EnglishArrowWhy people miss it
If A, then B / All A are BA → BThe base case. Contrapositive ¬B → ¬A is free and automatic.
A only if BA → B"Only if" marks the necessary side. It does NOT flip to B → A.
Only A are BB → A"Only" + noun flips it. Only members vote: voter → member.
A requires / depends on BA → BThe required thing is necessary, so it goes on the right.
Unless A, B¬A → BNegate the "unless" term, make it the trigger. Same for "without" and "except."
No A are BA → ¬BAlso yields B → ¬A. "None" statements are just conditionals with a negation.
A if BB → A"If" introduces the sufficient side wherever it appears in the sentence.
Some A are BA ←s→ BReversible, ∃ overlap. Cannot be chained like arrows. No contrapositive.
04 · Quantifiers

The all / most / some ladder

Strength flows downhill only. "All" proves "most" proves "some." Nothing flows back up.

All
∀ · 100%
→
Most
>50%
→
Some
∃ · ≥1

Chains that produce inferences

  • All A→B + All B→C ⇒ All A→C
  • Some A↔B + All B→C ⇒ Some A are C
  • Most A→B + Most A→C ⇒ Some B are C
  • All A→B ⇒ Some B are A (if any A exist)

Dead ends dressed as inferences

  • Some A↔B + Some B↔C ⇒ nothing
  • Most A→B + Most B→C ⇒ nothing
  • All A→B ⇏ All B→A (illegal reversal)
  • Some A are B ⇏ Some A are not B

06 · Reality check

How this actually plays on test day

Where formal logic pays

  • Must Be True / Inference with stacked conditionals: diagram on paper, chain the arrows.
  • Parallel Reasoning: match the skeleton, ignore the subject matter entirely.
  • Flaw questions: a large chunk are affirming the consequent or denying the antecedent in a trench coat.
  • Sufficient Assumption: find the gap in the chain, the answer is the missing arrow.

Where it doesn't

  • Causal reasoning (correlation vs causation) runs on different machinery.
  • Strengthen / Weaken lean on argument structure and evidence weight, not deduction.
  • Time math: diagramming everything is a trap. Write only for dense 3+ conditional chains; run the rest mentally. Formal logic covers maybe 40 to 50% of LR. Best case it's a huge edge, it is not the whole test.
