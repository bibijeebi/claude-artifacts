The PC Upgrade

Your computer is slow because both your drives are spinning hard drives. The new SSD is going to feel like buying a brand new PC. Plus we're doing a fresh Windows install, so any old malware gets nuked. Total time: ~90 minutes hands-on, plus install time you can walk away from.

Why this fixes everything

HDDs read at ~100 MB/s. The cheapest SATA SSD reads at ~550 MB/s. That's 5× faster, but it feels like 20× because Windows + games + browsers do thousands of tiny reads at once, which is the thing HDDs are catastrophically bad at. Boot time goes from 90 seconds to 12. Game load times drop in half. Programs open instantly instead of stuttering. This is the single biggest upgrade you can do to a PC for under $100.

1. What you need

  • 512 GB SATA SSD (the one from Amazon — already bought)
  • The PC with its current HDDs (we'll keep those)
  • USB stick, 8 GB or bigger. Anything you have. Files on it will be wiped.
  • Phillips screwdriver (Phillips #1 or #2). The cheap one in your toolbox.
  • A SATA data cable. Probably came in the SSD box. If not, an Amazon 2-pack is $5. They're red or black, thin, and L-shaped on each end.
  • A spare SATA power cable from the power supply inside the PC. Almost always there are extras dangling.
  • A working internet-connected PC or laptop to make the USB stick (yours, mom's, library — anything).

3. Make the install USB

Do this on your working PC or a laptop, not the slow one we're upgrading. Plug in the 8 GB+ USB stick.

  1. Download the Windows 11 ISO file from Microsoft. Go to microsoft.com/software-download/windows11. Scroll down to "Download Windows 11 Disk Image (ISO) for x64 devices." Pick "Windows 11 (multi-edition ISO for x64 devices)" → English (United States) → 64-bit Download. The file is ~6 GB, give it 5-10 minutes.
  2. Download Rufus from rufus.ie. Click the latest rufus-4.x.exe. It's 1.9 MB. No installer. Just save it to your Downloads folder and double-click to run it.
  3. Plug in the USB stick. Rufus will see it under "Device" at the top. Make sure it's the right drive — everything on it gets erased.
  4. Click "SELECT" and pick the Windows 11 ISO you just downloaded.
  5. Image option: "Standard Windows 11 Installation" (default).
    Partition scheme: GPT.
    Target system: UEFI (non CSM).
    Leave the rest at defaults.
  6. Click START. A "Windows User Experience" dialog pops up. Check ALL the boxes:
    • Remove requirement for 4GB+ RAM, Secure Boot and TPM 2.0
    • Remove requirement for an online Microsoft account
    • Create a local account with username
    • Set regional options to the same as this user's
    • Disable data collection (privacy questions)
    • Disable BitLocker automatic device encryption
    • (If you see it) Disable Teams, Outlook, Copilot and other Microsoft junk
    This is the magic step. It strips out all the Microsoft account harassment and pre-installed bloatware before Windows even installs.
  7. Click OK, then OK again to confirm USB wipe. Wait 8-15 minutes. When it says "READY" in green, eject the USB safely.

4. Install the SSD physically

Before you open the case

Shut down Windows fully (not sleep). Unplug the power cable from the wall. Press and hold the power button for 10 seconds — this drains the capacitors. Touch a metal part of the case with your bare hand to discharge static before touching anything inside.

  1. Open the side panel. Two thumbscrews on the back. The left side as you face the front of the PC is the one you want — that's where the motherboard is.
  2. Find a 2.5" mounting spot. Most cases have a dedicated 2.5" drive bay (a small flat tray, sometimes marked). If yours doesn't, use any 3.5" bay with the screw holes reaching, or honestly just velcro/double-sided tape it to the case floor — SSDs have no moving parts, they don't care. Don't let it dangle by the cables.
  3. Connect the SATA data cable. Plug one L-shaped end into the back of the SSD (the smaller of the two ports). Plug the other end into a SATA port on the motherboard — they're labeled SATA0, SATA1, SATA2, etc. Use SATA0 if you can see a free one (this becomes the boot drive).
  4. Connect the SATA power cable. Find a free SATA power connector on a black cable coming off the power supply. There are usually 2-3 free ones zip-tied somewhere. The wider connector plugs into the bigger port on the back of the SSD. Only fits one way — if it's not going in, flip it.
  5. Don't unplug the old HDDs yet. Just leave them connected. We'll wipe and reuse them later.
  6. Don't put the side panel back on yet. Wait until it boots successfully. If something's loose, you want to see it.
Pro tip: which port is which on the SSD

The back of the SSD has two ports next to each other. The smaller one (7 pins) is data. The bigger one (15 pins) is power. They're different sizes so you literally can't mix them up.

5. Boot the USB and install Windows

  1. Plug in the USB stick to a USB port on the back of the PC (front-panel USBs sometimes don't work for boot).
  2. Power on and immediately start mashing the boot menu key. It's one of these depending on your motherboard: F12, F11, F8, Esc, or Del. F12 is most common on AMD/MSI/Asus boards. If you miss it, restart and try a different one.
  3. Pick the USB stick from the boot menu (it'll say something like "UEFI: SanDisk USB" or whatever brand). Hit Enter.
  4. Windows installer loads. Pick English (US), keyboard US. Click Next.
  5. "Activate Windows" screen: Click "I don't have a product key". We'll activate after install — it's faster and lets you finish setup without typing the key on a keyboard with weird layout.
  6. Pick "Windows 11 Home" (or Pro if that's what you bought). It has to match the key you bought.
  7. Accept the license. Click "Custom: Install Windows only (advanced)". NOT "Upgrade".
  8. The drive selector is the dangerous part. You'll see a list of drives. The new SSD is the ~476 GB drive (512 GB minus formatting overhead). The old HDDs will be ~931 GB or larger. Identify the new SSD by size and verify it has zero existing partitions or one "unallocated space."
  9. Click on the new SSD's row. If there are any partitions on it (there shouldn't be), click each one and hit "Delete". Then click "Unallocated Space" and hit "Next". Windows creates the right partitions automatically. DO NOT touch the old HDDs in this screen — leave them alone.
  10. Wait 15-25 minutes. The PC reboots itself a few times. Pull out the USB stick when it first reboots so it doesn't try to boot the installer again. If you forget and it boots back into the installer, just power off, pull the stick, power on.
  11. First-time setup runs. Pick country, keyboard, name your PC. Because Rufus stripped the Microsoft account requirement, you'll get to "Who's going to use this device?" and can type a normal name. Set a password (or skip it). Skip the privacy questions (turn everything off). Skip OneDrive setup. Skip Game Pass.
  12. Desktop appears. You're in. The PC is running on the SSD now.
If you accidentally chose the wrong drive

If you installed Windows on top of an old HDD, just power off, restart, boot from USB again, and redo Step 9 picking the correct (smaller) drive. You can always re-install. Nothing is permanent until you save data on it.

6. Activate Windows

  1. Open Settings (Windows key + I).
  2. Go to System → Activation.
  3. Click "Change product key" (might be under "Upgrade your edition of Windows").
  4. Paste the 25-character key from CJ's. Click Next.
  5. Wait 30 seconds. It says "Windows is activated." Done.
If activation fails

Restart and try again. If still failing: open Command Prompt as Admin (right-click Start → Terminal Admin) and run slmgr /ipk YOUR-KEY-HERE then slmgr /ato. If still failing, email CJ's support — they'll send a replacement key within hours.

7. Wipe and reuse the old HDDs as storage

The old C: and D: drives still have all the old Windows + malware + your stuff on them. We're going to nuke them and turn them into clean storage drives for games and files.

Last chance to grab anything

If there's anything on those old drives you want — photos, screenshots, docs, save files — copy it to a USB stick or your new SSD now before formatting. Once you format, it's gone. (Pro tip: C:\Users\YourName\Documents and Pictures are usually the only folders worth grabbing. Game saves are sometimes there, sometimes in AppData.)

  1. Right-click the Start button → "Disk Management".
  2. You'll see all your drives at the bottom. Identify the old HDDs by size (~1 TB or whatever they are) — they'll have multiple partitions on each.
  3. Right-click each partition on the old drives → "Delete Volume" → Yes. Repeat until each old drive shows as one solid black "Unallocated" bar.
  4. Right-click the unallocated space → "New Simple Volume" → Next, Next, Next. Name it whatever you want ("Games" or "Storage"). NTFS, default allocation. Quick format. Finish.
  5. Repeat for the second HDD if there is one. Now they show up as fresh empty drives in File Explorer (probably as D: and E:).
How to use them

Put games on one of the HDDs (Steam → Settings → Storage → Add Drive). Steam load times will be slower than from the SSD but a 1TB HDD is way bigger than your 512GB SSD. Use the SSD for Windows + your most-played games (DayZ, etc.). Use the HDD for movies, music, and games you only play sometimes.

9. If something goes wrong

"The PC won't boot from the USB stick"

Restart and mash a different boot menu key. F12, F11, F8, Esc, Del. If none work, you need to enter BIOS (usually Del or F2 right after power-on). In BIOS, look for "Boot Order" or "Boot Priority" and put the USB stick first. Save and exit. Also: try a different USB port — back panel ports work better than front.

"It boots back into the old Windows on the HDD"

You forgot to pull the USB stick out, or the BIOS still has the HDD as boot priority. Restart, mash the boot menu key, pick the new SSD this time. To make it permanent: enter BIOS, set the new SSD as #1 boot device, save and exit.

"Windows won't accept my product key"

Three causes: (1) you bought a Pro key but installed Home, or vice versa — those don't cross-activate. Fix: download the right ISO and reinstall, OR upgrade Home to Pro for free with the Pro key (Settings → Activation → Change product key). (2) The key is for a different region — email CJ's, they'll swap it. (3) You typed it wrong. Copy-paste from the email.

"It activated but says 'not activated' a few days later"

Run slmgr /ato from an Admin Command Prompt. If that fails, email CJ's. They have a replacement guarantee.

"DayZ still runs like ass"

That's the graphics card now, not the disk. Your Sapphire Dual-X 3GB is from 2013. It meets DayZ's minimum spec. Drop the in-game settings to Low, turn off shadows and view distance, and you should get 30-50 FPS. If you want better, the next upgrade is a used GTX 1060 / RX 580 off Facebook Marketplace ($60-100), which doubles your FPS. Benny said he might have a card in the garage — ask him.

"How do I tell if I'm running off the SSD or HDD now?"

Open Task Manager (Ctrl+Shift+Esc) → Performance tab. Look at the disks listed on the left. The one with C: next to it is your boot drive. Click it. Top right says "Type: SSD" or "Type: HDD". If you did this right, C: is SSD.

"Can I still get to my old files?"

Only if you didn't format the HDDs yet. Open File Explorer → "This PC" → click into D: or E: → look in the old Users folder. Once you delete the volumes in Disk Management, the data is gone (technically recoverable with software but not for free).
