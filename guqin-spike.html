▸ How to use this

  1. Set Bekah's guqin on a sturdy table. Place a USB mic 6–12 inches above the soundboard, pointing down at the strings.
  2. Click Start Listening and pick the right mic from the dropdown if it doesn't auto-pick.
  3. Pluck each open string a few times. Watch the lane bars light up. Verify each string maps to its correct lane (1=C2 thickest → 7=D3 thinnest).
  4. Click Calibrate to run the formal accuracy test. Pluck each string 5 times when prompted.
  5. Pass criterion: ≥95% of plucks classified to the correct string within ±50¢. If below, switch mics or move closer.
  6. Click Export Log to send Claude the full detection record for analysis.
