What the pre-assessment skipped — study this anyway

The PFKO only sampled SELECT/WHERE/JOIN-style SQL and surface concepts. The real OA also leans on: data security & governance (CIA triad, access control, encryption, backups, data quality), SQL write/DDL (CREATE/ALTER/DROP, INSERT/UPDATE/DELETE, GROUP BY/HAVING, explicit JOIN…ON), normalization depth (partial vs transitive dependency, BCNF, anomalies), and BI/architecture (OLTP vs OLAP, warehouse vs mart, star schema). These are loaded into the cram Notes and the mock's Data Security block.
